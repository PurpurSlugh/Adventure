**🗡️ Text Adventure Game**

A simple interactive text-based adventure built in Python.

Your choices determine what happens next.
Every decision matters.

**🎮 About the Game**

This project is a small terminal-based adventure where the player must make decisions such as:

Choosing between different paths

Answering yes/no questions

Facing consequences for invalid choices

The game uses modular functions to handle player input and branching logic.

**✨ Features**

Clean function-based structure

Input validation (left/right, yes/no)

Branching story paths

Terminal screen clearing for better immersion

Easy to expand
